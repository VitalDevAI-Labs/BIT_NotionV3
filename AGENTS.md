# Repository Agent Entry Point

This repository uses the company Vital Context framework.

Before planning or changing code, read `.vital_context/CONTEXT.md` and follow its routing instructions. For meaningful implementation work, identify or create a task record before editing. A task is not complete until verification and context reconciliation are recorded and `npm run context:check` passes.

Provider-specific behavior belongs in `.vital_context/agents/`; this file is only a discovery pointer.
