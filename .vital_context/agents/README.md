# AI Provider Adapters

These files help different AI tools enter the same Vital Context workflow. They are adapters, not independent project memories.

- `generic.md` - baseline behavior for any agent.
- `claude.md` - Claude/Claude Code discovery and handoff guidance.
- `codex.md` - Codex discovery and verification guidance.

All adapters inherit `../GOVERNANCE.md`. They must not duplicate requirements, architecture, status, or decisions.
